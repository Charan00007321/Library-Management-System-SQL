# 📚 Library Management System using SQL

## 📌 Project Overview
The Library Management System is a database project designed to organize and manage library operations. It includes information about books, authors, publishers, library branches, borrowers, book copies, and book loans.

The project uses structured datasets to represent library records and support data retrieval and analysis.

## 🎯 Project Objectives
- Organize book and author information.
- Maintain publisher and library branch records.
- Track borrowers and book loan details.
- Analyze book availability and borrowing activity.
- Practice SQL queries for database management and reporting.

## 🗂️ Dataset Description
This project contains seven CSV files:

| File | Description |
|---|---|
| `books (1).csv` | Book information |
| `authors (1).csv` | Author information |
| `publisher (2).csv` | Publisher details |
| `library branch (1).csv` | Library branch information |
| `borrower (1).csv` | Borrower records |
| `book copies (1).csv` | Book copies available at branches |
| `book loans (1).csv` | Book borrowing and loan records |
